# Findoly logo-aligned mobile UI

The provider portal uses the approved Findoly logo unchanged. The mobile interface now derives its core visual system from the logo:

- Findoly navy for primary navigation and actions
- Findoly orange for small emphasis, active navigation indicators and selected labels
- Findoly sky blue for focus and location details
- Neutral white cards and soft blue-grey page backgrounds

The update is presentation-only. Lead workflows, credits, payments, CRM synchronization, filters, grid/row preferences and mobile navigation behaviour remain unchanged.
