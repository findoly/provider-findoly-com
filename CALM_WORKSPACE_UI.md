# Findoly Calm Workspace UI

This release keeps the existing Business Workspace information architecture and provider workflows, while using a restrained, WhatsApp-inspired visual system.

## Visual principles

- White cards and navigation surfaces
- Soft neutral-grey page background
- One small accent colour for active navigation and primary actions
- Green, amber and red only for meaningful statuses
- Thin borders and minimal shadows
- No dark sidebar, gradients, decorative colour blocks or coloured lead-card bars
- Existing responsive and mobile navigation behaviour retained

No provider business logic, marketplace rules, CRM synchronization, wallet flow, payment flow, outcome flow or reminder logic was changed.
