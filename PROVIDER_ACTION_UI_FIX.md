# Provider Action UI and Mobile Navigation Fix

## Action language

The provider portal uses one shared action pattern:

- Call: white outline, phone icon and large readable label.
- WhatsApp: white outline with restrained green text.
- Open / Update / Unlock: full-width Professional Blue primary action with a trailing arrow where relevant.

The pattern is used on Marketplace, My Leads and Lead Detail.

## Visible common filters

The following filters appear without opening Advanced Filters:

- Category
- City
- Lead Intent
- Sort By

Advanced Filters retain PIN code, dates, outcome/activity, provider activity and credit-range controls.

## Mobile navigation

The mobile overlay begins outside the drawer width. It cannot cover, dim or intercept taps inside the sidebar. The drawer remains above the overlay, and all sidebar controls retain pointer and touch events.
